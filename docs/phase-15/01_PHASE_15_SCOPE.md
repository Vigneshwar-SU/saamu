# Phase 15 — Production Hardening & Operational Readiness

## Objective
Prepare Saamu Tailors Version 1 for reliable day-to-day shop usage without introducing new business modules.

## In Scope
- Application-wide reliability and error handling review.
- Backend API consistency and defensive validation review.
- Frontend loading, empty, error and retry states.
- Authentication/session expiry behavior.
- OWNER/STAFF permission regression review.
- PostgreSQL backup and restore workflow for the local Windows deployment.
- Production configuration review.
- Auditability review for important financial and operational actions.
- Performance review for existing dashboard/report/list queries.
- Final regression and readiness checklist.

## Out of Scope
- New business features.
- Cloud deployment.
- WhatsApp/SMS integration.
- Payment gateways.
- GST/double-entry accounting.
- Report export/PDF.
- Major UI redesign.
- Removing legacy database tables unless separately approved.
