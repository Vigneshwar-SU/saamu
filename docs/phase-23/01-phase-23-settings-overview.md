# Phase 22 — Settings Module

## Objective
Complete the Settings module for Saamu Tailors without duplicating functionality that already exists.

## Goals
- Audit existing Settings/ShopDetails functionality first.
- Provide a real Settings UI.
- Reuse existing authoritative models, APIs and services.
- Preserve OWNER/STAFF RBAC.
- Persist supported shop/business configuration.
- Keep secrets and developer/deployment configuration out of the UI.
- Include automated verification and a manual checklist.

## Scope
Business/shop configuration, current-account information, and only meaningful application preferences already supported by the project.

## Out of Scope
Cloud infrastructure, database administration, environment variables, secrets/API keys, Django developer configuration, and unrelated business features.
