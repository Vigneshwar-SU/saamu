- Live local → cloud migration.

- Automatic WhatsApp/SMS/email sending.
- Provider webhooks/delivery tracking.

- New business modules.
- UI redesign.
- Human-executed manual verification.

## Guardrails
- No credentials in Git.
- No secrets in frontend bundles.
- No destructive browser endpoints.
- No arbitrary shell execution.
- No real production data in automated tests.
- No provider lock-in without explicit scope.
- No schema changes without explicit need.
- No claims of completed deployment when only readiness work was performed.
- Manual verification remains NOT STARTED unless the operator performs it.
