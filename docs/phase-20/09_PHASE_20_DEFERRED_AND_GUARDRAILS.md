# Phase 20 — Deferred Items & Guardrails

## Deferred
- Actual production cloud deployment.
- Cloud provider account/infrastructure provisioning.
- Automated cloud backup storage.
- Scheduled cloud backups.
- Object storage for media.
- CDN.
- Automatic WhatsApp/SMS/email sending.
- Provider integrations and webhooks.
- Message delivery tracking.
- Payment gateways.
- GST.
- Double-entry accounting.
- Bank/cloud accounting integration.
- New business modules.

## Guardrails
- Never commit secrets.
- Never expose secrets through API responses.
- Never accept arbitrary shell commands.
- Never provide browser-triggered database restore/migration.
- Never delete local data as part of migration.
- Never treat successful backup transfer as proof of successful application migration.
- Never claim cloud migration is complete without human verification.
- Keep local → cloud migration reversible until the cloud environment is proven.
