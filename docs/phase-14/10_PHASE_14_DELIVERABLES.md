# Phase 14 — Deliverables and Completion Criteria

## Backend
- Reusable reporting service(s).
- Read-only reporting API.
- Date filtering.
- Operational and financial aggregations required by scope.
- Aggregation correctness tests.
- RBAC tests.

## Frontend
- Reports page.
- Summary sections/cards.
- Appropriate charts/breakdowns where useful.
- Date filters.
- Loading/error/empty states.
- React Query integration.

## PASS Criteria
- Scope implemented.
- Reports derive from authoritative existing data.
- No duplicate financial system.
- Backend RBAC enforced.
- Automated tests pass.
- Full regression suite passes.
- Frontend lint/typecheck/build pass.
- Documentation updated.
- Manual verification remains NOT STARTED until actually performed.

Do not start Phase 15 during Phase 14.
