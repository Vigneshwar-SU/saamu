# Phase 18 — Frontend Specification

## Required Actions
- Copy WhatsApp Message
- Open WhatsApp

## UX
- Show a brief copy-success state.
- Prevent duplicate actions.
- Preserve the current page and existing state.
- Do not navigate away merely to prepare a message.
- Disable Open WhatsApp when no usable number exists.
- Show retryable clipboard/API errors.

## Message Preview
Where space permits, show a compact preview before handoff without exposing unrelated private information.

## Reuse
Create reusable communication UI/hook logic rather than duplicating WhatsApp URL and clipboard code.

## Styling
Follow the existing ERP design system. No unrelated redesign.
