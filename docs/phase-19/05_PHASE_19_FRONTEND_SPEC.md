# Phase 19 — Frontend Specification

The frontend is an operator review surface, never an automatic sender.

Where a safe existing location is identified, the UI may show:
- reminder type;
- appropriate order/customer reference;
- eligibility/status;
- prepared message preview;
- Phase 18 WhatsApp handoff action.

Include loading, empty, error/retry, and duplicate-action states.

Never calculate authoritative payment balances or lifecycle eligibility on the client.
