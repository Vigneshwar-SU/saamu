# Phase 19 — Deferred Items & Guardrails

## Deferred
- Automatic WhatsApp sending.
- Meta/WhatsApp Business API.
- Twilio/provider integration.
- SMS/email delivery.
- Provider credentials/tokens.
- Webhooks.
- External background senders.
- Cloud scheduler/deployment/backup automation.
- Payment gateways, GST, double-entry accounting.
- New payment/invoice types.
- Generic file management.
- Unrelated UI redesign.

## Guardrails
Never invent business rules, turn preparation into automatic sending, expose credentials, log full phone numbers, claim handoff equals delivery, bypass RBAC, duplicate authoritative calculations, or add migrations merely for convenience.
